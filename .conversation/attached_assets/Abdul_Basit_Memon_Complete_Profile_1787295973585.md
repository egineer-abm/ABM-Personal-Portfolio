## Applied Generative AI Cohort — 100x Engineers (Completed June 2026)

A 6-month deep dive that shaped a huge chunk of how I build today, structured across three modules:

**Module 1 — Diffusion Models:** Started with tensor.art and SDXL, learned the full pipeline (latent space, noising/denoising, VAE encode/decode), then moved into ComfyUI — text-to-image, image-to-image, ControlNets, inpainting, IPAdapters, LoRA training on faces and styles, and the newest models (Flux, Qwen Image, Z-Image, Wan Animate, Infinite Talk).

*Capstone:* I built a full **digital clone of myself** — trained a Flux LoRA on 30 labeled images of my face, generated consistent images of myself with Flux Dev, cloned my own voice with Chatterbox TTS from a single speech sample, then animated everything together using Wan Animate (Infinite Talk) on an H100 GPU instance to get a fully lip-synced video of myself speaking in my own voice.

**Module 2 — LLMs & Applications:** Covered the OPT framework (Operating-model, Process, Task) for turning an idea into a real spec, PRD prompting, building UIs in Gradio/Streamlit, designing and deploying FastAPI backends, and full database design (domain modeling, ERDs, Postgres/Supabase). Combined it all into a real full-stack pipeline: **Streamlit/Gradio + FastAPI + Supabase**. Also went deep on prompt engineering, context engineering, token economics and pricing models, tool calling, MCPs (building and deploying an MCP server with FastMCP), RAG (chunking strategies, embeddings, cosine similarity, vector search, RAGAS evaluation), and how memory systems work behind tools like Claude, Gemini, and ChatGPT (and how mem0/Supermemory approach it).

**Module 3 — AI Agents:** Learned the SPAOR loop (Sense, Plan, Act, Observe, Reflect), built simple and multi-agent systems with tool calling using Groq, and worked on guardrails and evals to make agents production-ready.
