### Detailed Project Descriptions

#### 1. AGERE — Agentic Recruiter
- **Event / Program**: Google Intensive Agentic AI Course Capstone Project (2025)
- **Tech Stack**: Google Agent Development Kit (ADK), RAG Architecture, Streamlit, Gemini API
- **Team**: International Collaboration (Pakistan, UK, France, Italy)
- **Link**: [Kaggle Competition Writeup](https://kaggle.com/competitions/agents-intensive-capstone-project/writeups/agere-agentic-recruiter)
- **Description**: An intelligent recruitment agent designed to streamline candidate experience and hiring workflows. AGERE assists candidates dynamically through interview phases, provides intelligent evaluation, and assists HR teams in screening and candidate management.

#### 2. BITA — Local AI OCR Vendor Invoice Manager
- **Context**: Google Startup: Prompt to Prototype Course Participation
- **Tech Stack**: Gemini OCR API, React + Vite
- **Status**: Functional local desktop/web application (working prototype)
- **Description**: A local-first application designed for local brands and businesses to automate vendor invoice digitization using AI OCR. Key capabilities include:
  - Automated vendor profile creation and management.
  - Multi-invoice tracking and link association with vendor accounts.
  - Real-time price tracking and fluctuation analysis.
  - Invoice status and payment monitoring in a completely local environment.

#### 3. Kutbi — YouTube Learning & Workout Extractor
- **Architecture**: Local & Open-Source Application
- **Tech Stack**: FastAPI (Backend), Streamlit (UI), Groq / OpenRouter API, `yt-dlp` / YouTube Data API
- **Description**: An interactive video processing platform that converts YouTube videos or entire channel feeds into actionable, 5-minute practical exercises and structured summaries.
- **Key Features**:
  - **Feed Processing**: Input channel handles or video links; retrieves customizable video lists.
  - **Resource Optimization**: Processes up to 2 videos concurrently to minimize API costs and credit consumption.
  - **Transcription & Extraction**: Automatically pulls transcripts and generates structured timelines, key topics, resource links, required tools, and executable code snippets.
  - **Actionable Outputs**: Converts raw video transcripts into step-by-step 5-minute practical exercises.

#### 4. Tool Stash — Agentic Bookmark & Tool Discovery
- **Deployment**: [https://abm-tools.lovable.app/](https://abm-tools.lovable.app/)
- **Tech Stack**: Vibe-Coded Agentic AI Architecture, Notion Database API, Web Search Tools
- **Description**: An agent-driven web bookmarking system equipped with a Human-in-the-Loop (HITL) approval layer. Users describe software tools or web links in natural language, and the agent searches the internet, provides context, and prompts the user before persisting bookmarks into an organized Notion database. Features a visual dashboard library to explore saved tools.

#### 5. Manzil-Ikigai — Purpose & Goal Discovery Bot
- **Tech Stack**: Gemini AI API
- **Status**: Active Development
- **Description**: An AI discovery assistant built around the Japanese *Ikigai* framework ("reason for being"). It guides users through multi-stage reflective questioning to identify core motives, clarify career and life goals, discover latent personal strengths, and build actionable roadmaps toward self-actualization.

#### 6. SB0 — Second Brain Cognitive Engine
- **Repository**: [https://github.com/abm1119/SB0](https://github.com/abm1119/SB0)
- **Tech Stack**: Gemini API (Bring Your Own Key / BYOK), RAG Architecture, Interactive Graph Visualizer
- **Description**: A local-first knowledge management system featuring an interactive Knowledge Base Graph.
- **Key Features**:
  - **Multi-Format Previews**: Renders PDFs, Markdown (`.md`), images, and document files natively in-app.
  - **Cognitive Engine**: Powered by semantic Retrieval-Augmented Generation (RAG) to query knowledge bases naturally and fetch precise context.
  - **Dynamic Triggers**: Includes customizable modification triggers to auto-update and organize interconnected knowledge nodes.

#### 7. Roznama — Minimalist Daily Notes & Wiki Engine
- **Access**: Private Repository (Available on Demand)
- **Tech Stack**: Markdown Files, Git Synchronization, Offline Search Engine, Custom Agent Skills
- **Description**: A minimalist, distraction-free daily notes app and personal wiki system.
- **Key Features**:
  - **Git Sync**: Automatic version control and backup across devices.
  - **Skill Integration**: Connects with CLI tools and agentic environments (Gemini-CLI, Cursor, Claude Code) using pre-built integrations.
  - **Offline Cognitive Engine**: No external AI required. Features fast slash (`/`) commands, fuzzy text matching, and visual mapping of related and connected notes.

#### 8. Notion Vault — Portable Local Password Manager
- **Repository**: [https://github.com/abm1119/password-manager-vault/releases](https://github.com/abm1119/password-manager-vault/releases)
- **Tech Stack**: Python (Tkinter + `ttkbootstrap`), Flask, Waitress, SQLite3, Node.js, Companion Chrome Extension
- **Description**: A portable, offline, open-source password manager built for complete privacy and security without reliance on cloud infrastructure.
- **Key Features**:
  - Distributed as a lightweight standalone executable (`.exe`).
  - Native Chrome extension support for seamless in-browser password filling.
  - SQLite3 local encrypted database.

#### 8A. Notion Vault CLI — Natural Language Encrypted Vault
- **Package**: `pip install notion-vault-cli`
- **Tech Stack**: Python, SQLite, Natural Language Processing
- **Description**: A private, locally encrypted command-line password vault operated through plain English prompts.
- **Key Features**:
  - Zero cloud sync, zero external dependencies, and no account setup.
  - Single master password authentication.
  - Plain-English natural language commands for credential retrieval, storage, and cross-domain folder organization.

### Mobile Applications

#### TechdioApp
- **Tech Stack**: .NET MAUI, C#, SQLite + Firebase, XAML (2024)
- **Links**: [App Screens](https://github.com/abm1119/TechdioApp/blob/ad0ddb6ec780a06ef24d9a16ab8e5e2883b62449/Techdio-AppScreens.png) | [GitHub Repository](https://github.com/abm1119/TechdioApp)

- **Background & Learning Highlights**: Developed during the 7th semester out of a passion for .NET MAUI. Served as a hands-on exploration of building APK binaries, implementing MVVM/MVM architecture, handling CRUD operations, and designing REST APIs in C#.

#### Intelligent Carpooling App
- **Tech Stack**: Android Studio, Java + Kotlin, Firebase Realtime Database, Mapbox Maps API, A* Search Algorithm
- **Links**: [Demo Video](https://vimeo.com/1102623700?fl=pl&fe=sh) | [GitHub Repository](https://github.com/urooj-marvi/Carpooling_App)
- **Description**: A full-featured mobile carpooling solution offering real-time ride matching, secure payments, and live GPS route tracking using Mapbox.
- **Thesis & Technical Contribution**: Final Year Capstone Project for Bachelor of Engineering in Computer Systems Engineering. Authored a accompanying research thesis evaluating route matching and overlap feasibility using the A* algorithm compared to Dijkstra or standard greedy approaches to reduce resource utilization and compute overhead.

### Hardware & Robotics Systems

#### Arduino Vehicle Speed Detector
- **Tech Stack**: Arduino Uno, IR Sensors, 16x2 LCD Display, C++, Arduino IDE
- **Link**: [GitHub Repository & Demo](https://github.com/abm1119/Arduino-Vehicle-Speed-Detector-)
- **Description**: An IR-based speed detection system using sensor break-beams to measure vehicle speed and display measurements in real-time on an LCD output with high accuracy.
- **Background**: Completed during 1st Semester Engineering Workshop as a two-person team project, marking an initial hands-on milestone with circuit design, sensor calibration, and microcontrollers.

#### Arduino-Based Crane with Servo Motors
- **Tech Stack**: Arduino UNO, 90-Degree Servo Motors (x2), Mini Joystick Module, Pictoblox, C++, Arduino IDE
- **Links**: [Video Demo](https://www.playbook.com/s/computer-systems-engineeing/HMoaREBPy6L1mzWnEouCkgfx) | [GitHub Repository](https://github.com/abm1119/Arduino-Crain-by-Pictoblox-Interfacing-)
- **Description**: A robotic crane driven by dual servo motors and controlled via a mini joystick module, utilizing block-based logic via Pictoblox for horizontal and vertical axis manipulation.
- **Background**: Created in 2nd Semester as an independent self-guided experiment, designing custom curriculum exercises for microcontrollers without formal course mentorship.

#### Arduino Night Patrol Surveillance Robot
- **Tech Stack**: Arduino Uno, IR Sensors, PIR Motion Sensor, Ultrasonic Sensor, Laser Module, Buzzer, Mobile Car Frame

- **Background**: Developed as the final Open Lab project in 7th Semester Robotics, demonstrating integrated embedded hardware systems.
