This is a working note rather than a finished essay. The idea is being kept here in its useful, slightly unfinished state — the way most of my better questions begin.

Building Local-First Software is part of a larger thread I keep returning to: how tools can make knowledge more accessible without making the person using them less curious. I am still collecting examples, building small systems, and trying to describe what changes when software meets an actual life.

The final version will arrive when it has earned its shape.
